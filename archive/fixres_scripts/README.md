# 归档说明（fixres_scripts）

⚠️ **本目录不是产品组件，请勿运行。**

这三个脚本是 2026 年 8 月针对某一批特定分析结果（硬编码路径
`/mnt/e/数据/new_run_results`）做的一次性修复与验证工具：

| 脚本 | 用途 |
|---|---|
| `inspect_xlsx.py` | 检查修复前 Excel 的列结构（只读诊断） |
| `fix_directions.py` | 把差异结果文件的"比较方向"列名批量改正 |
| `verify_fix.py` | 对照原始备份（BACKUP 目录）逐项验证修复正确性 |

它们与 RNA 分析网页（../app）无关，不会被网页调用，路径也是针对
当年那台机器、那批数据写死的，直接运行只会报错或改错文件。

保留它们仅用于历史追溯（当时修复了什么、如何验证的）。
如需处理类似问题，请以此为参考**复制一份改路径后**再使用。

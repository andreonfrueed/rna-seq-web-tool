# 迷你测试样例 example

这是一套**只有约 170KB 的迷你双端 FASTQ 数据**，用于安装后快速确认环境能跑通，不占磁盘、几分钟内出结果。

## 样本设计

| 样本 | 分组 | 文件 |
|---|---|---|
| CON_1 / CON_2 | 对照组 C | `CON_1_R1.fq.gz` `CON_1_R2.fq.gz` … |
| TREAT_1 / TREAT_2 | 处理组 T | `TREAT_1_R1.fq.gz` `TREAT_1_R2.fq.gz` … |

每个样本 200 条、长度 100bp 的随机序列（固定随机种子生成，可复现）。**数据是随机的，没有生物学意义**，只用来验证软件环境和分析流程是否正常。

## 两种用法

### 方式一：一键环境自检（推荐，最快）

双击 **`一键环境测试.bat`**，它会自动：

1. 把 8 个样例文件复制到网页的上传目录
2. 检查全部分析工具（pyseqrna / HISAT2 / STAR / samtools / FastQC / Trim Galore）
3. 验证样例文件完整性
4. 运行仓库内置的 51 项核心逻辑测试

全部通过即代表环境没问题，可以直接开始真实分析。

### 方式二：走一遍完整分析流程

1. 双击 `一键环境测试.bat`（把样例放进上传目录），或手动把 `fastq/` 里 8 个文件拖进上传文件夹
2. 打开网页 → **数据与参考文件** → 选物种（人/小鼠都行）→ 下载参考文件
3. 点 **扫描已有文件**，会识别出 CON_1/CON_2/TREAT_1/TREAT_2 四个样本
4. 到 **分组与参数**：CON_1/CON_2 选 C，TREAT_1/TREAT_2 选 T
5. 到 **运行分析**：起个名字，点开始

数据很小，几分钟到几十分钟就能跑完（取决于机器和参考文件构建）。跑通即代表比对、定量、差异、富集的整条流水线正常。**记住：这份结果的数字没有实际意义，验证完流程即可删除。**

## 注意

- 随机序列的比对率会很低，这是正常的，不代表工具出错
- 样例只在验证流程用，正式分析请使用你自己的真实测序数据
